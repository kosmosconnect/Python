Class 13 · def

Defining and calling a function

greet.py

def greet(name):
    print("Namaskar,", name)
    print("Welcome to ITER!")

greet("Ananya")
greet("Subham")

Output

Namaskar, Ananya
Welcome to ITER!
Namaskar, Subham
Welcome to ITER!

1

Define: def, a name, (parameter) and a colon

2

Call: greet("Ananya") runs the indented body
