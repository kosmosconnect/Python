Programs that make decisions

Yes

You make decisions all day, based on a condition.

If marks are 40 or more, pass. Else, fail.

If the signal is green, go. Else, stop.

If wallet has Rs. 50, buy the rasagolas.

In Python, the condition is any True/False expression, just like last week's comparisons.
