Class 5 · break and continue

Stopping early and skipping a round

break: stop the loop now

for n in range(1, 10):
    if n == 5:
        break
    print(n, end=" ")

1 2 3 4

continue: skip this round

for n in range(1, 10):
    if n % 3 == 0:
        continue
    print(n, end=" ")

1 2 4 5 7 8

Real use: keep asking for the PIN with while True: and break out when it is correct.
