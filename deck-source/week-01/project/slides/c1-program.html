Class 1 · The big idea

What is a program?

A program is a list of instructions that a computer follows exactly, one step at a time.

The computer is incredibly fast, but it has zero common sense. It does exactly what you write, not what you meant.

Programming means learning to give clear, step-by-step instructions.

Think of it like

A recipe for hostel Maggi

  1. Boil 1½ cups of water
  2. Add noodles and tastemaker
  3. Cook for 2 minutes, stirring
  4. Serve hot

Recipe = program · You = programmer · Cook = computer

Python Programming · Week 1 · Class 1

Start with the recipe analogy before showing any code. Ask: "What happens if I swap steps 1 and 3?" (You cook dry noodles: the order matters.) "What if I just write 'make Maggi'?" (A computer would not understand: every step must be spelled out.) Key message: computers are fast but literal. A program is a recipe the computer follows exactly. Bugs come from unclear or wrong steps, not from the computer "thinking wrongly".
