Class 2 · Input

Talking to the user with input()

greet.py

name = input("Enter your name: ")
city = input("Your city: ")
print("Hello", name, "from", city)

Output · orange = what the user types

Enter your name: Subham
Your city: Cuttack
Hello Subham from Cuttack

1

Shows the message

The text inside input() is a prompt for the user

2

Waits for Enter

The program pauses until the user types and presses Enter

3

Always gives text

Even if the user types 18, you get "18", a string

Python Programming · Week 1 · Class 2

Run greet.py live and let the student type the answers. Stress point 3: input() ALWAYS returns a string. This single fact causes most beginner bugs, which is exactly what the next slide is about. Tip: put a space at the end of the prompt ("Enter your name: ") so the typed text does not stick to the colon. Ask the student to change the program to also ask for their branch and print it.
