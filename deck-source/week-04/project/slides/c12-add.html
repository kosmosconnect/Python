Class 12 · Step 2

Adding and showing students

records.py · choices 1 and 2

# choice 1: add
name = input("Name: ").strip().title()
marks = []
for sub in ["Maths", "Physics", "Python"]:
    marks.append(int(input(sub + ": ")))
students[name] = marks
# choice 2: show
for name, m in students.items():
    print(name, m, f"{sum(m) / 3:.1f}")

Output · orange = what the user types

Name: ananya
Maths: 78
Physics: 85
Python: 92
Ananya [78, 85, 92] 85.0

.strip().title() turns " ananya" into "Ananya", so searching works later.
