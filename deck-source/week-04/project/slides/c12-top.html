Searching and finding the topper

records.py · choices 3 and 4

# choice 3: find
name = input("Find: ").strip().title()
if name in students:
    print(name, students[name])
else:
    print("Not found")
# choice 4: topper
best, best_total = "", -1
for name, m in students.items():
    if sum(m) > best_total:
        best, best_total = name, sum(m)
print("Topper:", best, best_total)

Output · orange = what the user types

Find: subham
Subham [65, 70, 88]
Topper: Ananya 255

The topper loop is the largest-number pattern from Week 3, using totals.
