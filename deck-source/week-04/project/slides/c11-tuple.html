Class 11 · Tuples

Tuples: lists that cannot change

tuples.py

point = (3, 4)
x, y = point
print(x, y)
days = ("Mon", "Tue", "Wed")
print(days[1], len(days))
# days[0] = "Sun"   TypeError!

Output

3 4
Tue 3

Round brackets. Indexing and slicing work, changing does not.

When to use

Fixed data: days of the week, a date, an (x, y) point.

A one-item tuple needs a comma: (5,)
