Class 11 · Counting

Counting letters with a dictionary

frequency.py

word = input("Word: ")
freq = {}
for ch in word:
    freq[ch] = freq.get(ch, 0) + 1
print(freq)

Output · orange = what the user types

Word: banana
{'b': 1, 'a': 3, 'n': 2}

1

New letter: get gives 0, so its count becomes 1

2

Seen before: its count goes up by 1

This counting pattern is one of the most useful in all of programming: votes, word counts, marks per grade. Trace banana: b new (1), a new (1), n new (1), a seen (2), n seen (2), a seen (3).
