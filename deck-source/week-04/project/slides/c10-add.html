Class 10 · Matrix addition

Adding two matrices

matrix_add.py

A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
C = []
for i in range(2):
    row = []
    for j in range(2):
        row.append(A[i][j] + B[i][j])
    C.append(row)
print(C)

Do the addition by hand first: add matching cells. Then trace i = 0: j = 0 gives 6, j = 1 gives 8, so row [6, 8] goes into C.
