Class 7 · Looping

Visiting every character

vowels.py

word = input("Word: ")
count = 0
for ch in word:
    if ch in "aeiouAEIOU":
        count += 1
print("Vowels:", count)

Output · orange = what the user types

Word: Konark
Vowels: 2

for ch in word gives you one character per round.

Read it as

for each character ch in word, do the indented block

ch in "aeiou" checks if ch is one of those letters.
