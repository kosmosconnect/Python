Class 8 · Checking

Is it digits? Is it letters?

password.py

pw = input("New password: ")
if len(pw) < 8:
    print("Too short")
elif pw.isdigit() or pw.isalpha():
    print("Mix letters and numbers")
else:
    print("Strong enough")

Output · orange = what the user types

New password: odisha2026
Strong enough

isdigit()

True if every character is 0–9: "2026"

isalpha()

True if every character is a letter: "Puri"

isupper() / islower()

True if all letters are capitals / small

Test with "abc" (too short), "12345678" (only digits), "odishaabc" (only letters) and "odisha2026". Real use: check that a phone number or roll number has only digits before converting it with int(), so the program does not crash: if roll.isdigit(): roll = int(roll). isalnum() is True for letters and digits mixed. Note that isdigit() of "-5" is False, because of the minus sign.
