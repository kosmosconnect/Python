Class 7 · Immutable

Strings cannot be changed in place

fix_name.py

name = "priyanka"
# name[0] = "P"   TypeError!
name = "P" + name[1:]
print(name)

Output

Priyanka

You cannot change a letter inside a string.

Instead, build a new string and store it in the same variable.

Immutable means cannot be changed. Lists (Class 9) are the opposite: mutable.
