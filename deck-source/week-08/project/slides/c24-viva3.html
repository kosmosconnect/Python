Files, errors and OOP

Class vs object?

Class: the blueprint. Object: one real instance made from it.

What is self?

The object the method was called on.

What is exception handling?

Catching run-time errors with try/except so the program does not crash.

w vs a file modes?

w erases and writes fresh. a adds to the end and keeps old data.
