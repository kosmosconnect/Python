Functions and collections

Parameter vs argument?

Parameter: the name in def. Argument: the value passed when calling.

What is recursion?

A function calling itself. Needs a base case or it never stops.

What is a lambda?

A small one-line function with no name: lambda x: x * 2.

What is a dictionary?

Key–value pairs, looked up by key: {"Puri": 3}.
