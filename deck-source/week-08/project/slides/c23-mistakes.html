Class 23 · Common mistakes

Mistakes that cost marks

= vs ==

= stores a value, == compares. if x = 5: is a syntax error.

input() is text

Convert with int() or float() before doing maths.

range stops early

range(1, 10) ends at 9. Use range(1, n + 1).

print vs return

A function that prints gives back None. Return what the caller needs.
