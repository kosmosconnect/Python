The Library class: issue and return

library.py

class Library:
    def __init__(self):
        self.books = {}            # bid -> Book
    def add(self, book):
        self.books[book.bid] = book
    def issue(self, bid, name):
        book = self.books[bid]
        if book.holder:
            raise ValueError("Already issued")
        book.holder = name
    def give_back(self, bid):
        self.books[bid].holder = ""

A dictionary of Book objects, so finding a book by id is instant.

Wrong ids and double issues raise errors. The menu catches them.
