Saving and loading the books

library.py · inside Library

def save(self):
    with open(FILE, "w", newline="") as f:
        w = csv.writer(f)
        for b in self.books.values():
            w.writerow([b.bid, b.title,
                        b.author, b.holder])

def load(self):
    if os.path.exists(FILE):
        with open(FILE) as f:
            for row in csv.reader(f):
                self.add(Book(*row))

1

save: rewrite the whole file after every change

2

load: rebuild each Book from a CSV row

Book(*row) spreads the 4 values of the row into the 4 parameters.

Python Programming · Week 8 · Class 22

Both are methods of Library, so they are indented inside the class in the real file. Mode "w" is right here because we write the complete, current list every time. Book(*row) is the unpacking star: Book(*["B1", "Wings", "Kalam", ""]) is the same as Book("B1", "Wings", "Kalam", ""). Run the program, issue a book, quit, run again: the book is still issued.
