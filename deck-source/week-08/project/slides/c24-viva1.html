Basics

Is Python compiled or interpreted?

Interpreted: it runs line by line (after turning code into bytecode).

Mutable vs immutable?

Mutable can change in place (list, dict, set). Immutable cannot (int, str, tuple).

List vs tuple?

List: [ ], can change. Tuple: ( ), fixed, a bit faster, can be a dict key.

Why indentation?

Python uses it to group lines into blocks, where C uses { }.
