Loading saved expenses

expenses.py

import csv, os
FILE = "expenses.csv"

def load():
    data = []
    if os.path.exists(FILE):
        with open(FILE) as f:
            for row in csv.reader(f):
                data.append(row)
    return data

1

First run: no file yet, so return an empty list

2

Later runs: each CSV row becomes a list

os.path.exists checks first, so a missing file never crashes the program.
