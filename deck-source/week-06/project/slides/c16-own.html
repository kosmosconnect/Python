Class 16 · Your own module

Any .py file is a module

mytools.py

def is_even(n):
    return n % 2 == 0

def area(r):
    return 3.14159 * r * r

main.py (same folder)

import mytools
print(mytools.is_even(8))
print(mytools.area(2))

Never name your file math.py or random.py: Python would import yours instead of the real one.
