Writing a list to a file

save_cities.py

cities = ["Bhubaneswar", "Cuttack", "Puri"]
with open("cities.txt", "w") as f:
    for c in cities:
        f.write(c + "\n")

with open("cities.txt", "a") as f:
    f.write("Konark\n")
print("Saved!")

Output

Saved!

cities.txt now holds

Bhubaneswar
Cuttack
Puri
Konark

Open the file in Notepad to check. Run it twice: "w" starts fresh each time, "a" keeps adding.
