Dice, OTPs and lucky draws

lucky.py

import random
dice = random.randint(1, 6)
otp = random.randint(1000, 9999)
snack = random.choice(["Samosa", "Bara",
                       "Gupchup"])
names = ["Ananya", "Subham", "Priyanka"]
random.shuffle(names)
print(dice, otp, snack)
print(names)

Output

4 7392 Bara
['Priyanka', 'Ananya', 'Subham']

randint(a, b)

a whole number from a to b, both included

choice / shuffle

pick one item / mix the whole list
