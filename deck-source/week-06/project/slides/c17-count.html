Class 17 · A file program

Counting lines, words and characters

wc.py

name = input("File: ")
lines = words = chars = 0
with open(name) as f:
    for line in f:
        lines += 1
        words += len(line.split())
        chars += len(line)
print(f"{lines} lines, {words} words, {chars} chars")

Output · orange = what the user types

File: cities.txt
4 lines, 4 words, 32 chars

A classic lab program: Week 3's split() and len(), now on a whole file.

lines = words = chars = 0 sets all three to 0 in one line.

chars counts the \n at the end of each line too: Bhubaneswar 11 + Cuttack 7 + Puri 4 + Konark 6 = 28 letters, plus 4 new-line characters = 32. Variations for practice: count how many lines contain a given word, find the longest line, or copy one file to another with every line in capital letters.
