Class 19 · A useful tool

Keep asking until the input is valid

get_int.py

def get_int(prompt):
    while True:
        try:
            return int(input(prompt))
        except ValueError:
            print("Not a number, try again")

marks = get_int("Marks: ")
print("Saved", marks)

Output · orange = what the user types

Marks: eighty
Not a number, try again
Marks: 80
Saved 80

Write it once, use it in every program.

Use it in the record manager and expense tracker so wrong typing never crashes them.
