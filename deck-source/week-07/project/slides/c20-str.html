Class 20 · __str__

Printing an object nicely

student_str.py

class Student:
    def __init__(self, name, roll):
        self.name = name
        self.roll = roll

    def __str__(self):
        return f"{self.roll}: {self.name}"

s = Student("Ananya", 21)
print(s)

Output

21: Ananya

Without __str__

print(s) shows something like <__main__.Student object at 0x7f…>

With __str__

print(s) uses the text your method returns

Python Programming · Week 7 · Class 20

__str__ must RETURN a string, not print it. It is called automatically by print() and str(). This is a first taste of "special methods" (dunder methods); others like __len__ and __eq__ exist but are not needed now.
