Class 21 · Polymorphism

Same method name, different behaviour

shapes.py

class Rectangle:
    def __init__(self, l, b):
        self.l, self.b = l, b
    def area(self):
        return self.l * self.b
class Circle:
    def __init__(self, r):
        self.r = r
    def area(self):
        return 3.14159 * self.r ** 2
for s in [Rectangle(4, 5), Circle(1)]:
    print(type(s).__name__, round(s.area(), 2))

Output

Rectangle 20
Circle 3.14

One loop calls area() on every shape. Each shape knows its own formula.

Poly = many, morph = forms. One name, many forms.

Python Programming · Week 7 · Class 21

Polymorphism means code can treat different objects the same way, as long as they have the same method. The loop does not care whether s is a rectangle or a circle. In bigger programs both classes would inherit from a Shape parent with its own area(). Built-in example: len() works on strings, lists and dictionaries, and + adds numbers but joins strings.
